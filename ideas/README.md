## 本类型约定

- 文件名可以是中文，`title` 不加编号；`index.md` 一般使用默认的 `post_sort: published_at_desc`。
- 图片放在专栏的 `assets/` 或 `media/` 目录，用相对于当前 Markdown 文件的路径引用。
- 新文章必须显式填写全仓库唯一的 `slug`；移动文章时保留原 slug。

完整格式见仓库根目录的 [AGENTS.md](../AGENTS.md)。
