## 本类型约定

- 每个专栏都是系列：文件名 `NN-<英文短名>.md`，`title` 以同样的 `NN-` 开头，`index.md` 设 `post_sort: title_asc`。
- `index.md` 正文写系列简介和按篇章分组的文章列表，链接用 `./NN-xxx.md` 相对路径。
- 图片放在专栏的 `assets/` 目录。

新增专栏或文章的完整格式见仓库根目录的 [AGENTS.md](../AGENTS.md)。新增专栏后请同步更新上表。
