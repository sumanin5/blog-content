- 文件名可以是中文，`title` 不加编号；`index.md` 一般用默认的 `post_sort: published_at_desc`。
- 图片放在专栏的 `media/` 或 `assets/` 目录，用相对路径引用。

完整格式见仓库根目录的 [AGENTS.md](../AGENTS.md)。
